1.2 프로젝트의 차별점
기존 방식이나 유사 서비스와 비교해 달라지는 점을 3가지 이내로 작성합니다.
1. 쿠폰히어: 쿠폰 이미지 기반으로 브랜드, 상품명 등을 인식 후 사용자가 매장 근처 진입시에 팝업 알림
2. 카득: 현재 위치와 소비상황에 따라 그 장소에서 혜택이 가장 좋은 카드 추천
3. 포콘: 기프티콘 이미지 등록 후 유효기관 관리, 현재 위치를 기준으로 사용 가능한 매장을 지도에 표시
세가지의 기존 서비스 모두 국소적 서비스 영역에서만 관리. 통합서비스는 존재하지 않음
해당 서비스는 혜택의 적용 순서·중복 가능 여부·최소 결제액·월간 할인한도·전월실적·간편결제 제외 여부까지 계산을 목표
SECTION 02
문제 정의와 근거
문제정의  기술이나 기능에서 출발하지 말고, 실제 사용자가 겪는 문제와 그 문제의 크기·빈도·영향을 근거로 설명합니다.
2.1 문제 배경과 현황
문제가 발생하는 맥락, 현재 상태, 왜 지금 해결해야 하는지를 작성합니다.
모바일 상품권은 구매·전달·사용이 편리하지만, 사용자는 유효기간과 보유 여부를 놓치기 쉽다. 한국소비자원 조사에서는 모바일 상품권 이용 경험자 500명 중 52.0%가 유효기간 만료 시까지 상품권을 사용하지 못했고, 이 중 45.0%는 만료 통지를 받지 못했다고 응답했다. 미사용자 중 63.5%는 별다른 조치를 하지 않았으며, 전체 응답자의 78.0%는 유효기간 만료 후 미사용 금액의 90% 환불 가능 사실을 몰랐다. 즉 “가지고 있지만 제때 사용하지 못하는 문제”가 실제 소비자 문제로 확인된다.한편 결제 혜택은 쿠폰, 카드, 통신사 멤버십 등 여러 채널에 분산되어 있고 각각 최소 결제액, 할인 한도, 전월 실적, 중복 가능 여부가 달라 결제 직전 사람이 직접 최적 조합을 계산하기 어렵다. 기존 앱들도 위치 알림 또는 카드 추천, 통합 할인 추천을 제공하고 있어 문제 수요는 검증되어 있으나, 공식 근거 표시와 재현 가능한 계산 규칙을 중심으로 한 구현은 여전히 차별화 포인트가 된다.본 MVP는 공공데이터포털의 전국 상가(상권)정보를 이용해 “현재 위치 → 주변 매장 후보”를 판별하고, 공정거래위원회 브랜드 데이터와 alias 규칙으로 매장을 쿠폰의 표준 브랜드에 연결한다. 이후 해당 브랜드에서 사용할 수 있는 보유 쿠폰과 공식 카드·통신사 혜택만 검색하여 추천하는 흐름을 검증한다. 전국지역화폐가맹점 데이터는 매장 교차검증과 향후 지역화폐 결제수단 확장에 활용한다.

2.2 핵심 문제 진술문
대상, 상황, 어려움, 원인 또는 제약, 해결했을 때의 변화를 포함합니다.
모바일 쿠폰을 여러 장 보유한 사용자는 역·상업시설 등 실제 결제 장소에 도착했을 때, 어떤 쿠폰이 있는지와 카드·통신사 혜택을 동시에 기억하고 적용 조건까지 비교하기 어렵다. 원인은 쿠폰 정보가 이미지/메신저에 분산되어 있고, 혜택 조건도 각 제공사의 문서와 앱에 흩어져 있으며, 여러 할인 수단의 적용 순서와 중복 조건을 사용자가 직접 계산해야 하기 때문이다. 이를 해결하면 사용자는 매장에 도착한 시점에 바로 사용할 수 있는 쿠폰과 가장 유리한 결제 조합을 확인해 미사용·만료 및 혜택 누락을 줄일 수 있다.
2.3 문제 원인과 결과
표면적 현상과 근본 원인을 구분하고, 해결 대상이 아닌 외부 요인도 표시합니다.
[표면적 현상]- 보유 쿠폰을 잊거나 유효기간이 지난 뒤 발견한다.- 계산대 앞에서 카드/통신사 앱을 각각 열어 혜택을 확인한다.- 할인 조건이 복잡해 가장 유리한 조합을 포기하고 평소 결제수단을 사용한다.[근본 원인]- 쿠폰이 비정형 이미지로 분산되어 구조화·검색되지 않음- 현재 위치라는 “사용 맥락”과 쿠폰 데이터가 연결되지 않음- 카드/통신사 혜택이 서로 다른 문서에 흩어지고 규칙이 복잡함- 자연어 혜택을 수치 규칙으로 바꾸고 조합 계산하는 계층이 없음[외부 요인/제약]- 카드·통신사 정책은 수시로 변경될 수 있음- 코레일유통 공공데이터만으로는 일반 상권 전체를 커버하지 못함- 실제 전월 실적/월간 잔여 할인한도는 카드사 연동 API 없이는 자동 확인이 어려움

Agent는 사용자의 미사용 쿠폰, 등록 카드/통신사 정보, 매장 정보를 불러온다.5. RAG가 해당 매장/업종에 적용될 수 있는 공식 카드·통신사 혜택 조항을 검색한다.6. calculator tool이 “쿠폰만 사용 / 쿠폰+카드 / 통신사+카드 / 사용 가능한 기타 조합”의 최종 금액을 계산한다.7. 앱은 가장 저렴한 옵션과 차선 옵션, 예상 절감액, 적용 조건과 공식 출처를 팝업으로 보여준다.8. 사용자는 결제 후 쿠폰을 ‘사용 완료’로 표시한다.
