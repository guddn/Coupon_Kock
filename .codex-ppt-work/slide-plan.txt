Communication job: 채용 담당자와 기술 리뷰어가 쿠폰콕을 단순 데모가 아니라 문제 정의부터 배포·검증까지 완결한 풀스택 AI 프로젝트로 이해하게 한다.

1. Cover — 쿠폰콕 / 위치 기반 쿠폰 혜택 에이전트
2. Problem — 보유 혜택과 결제 맥락이 분리되어 있다
3. Solution — 등록→탐색→추천의 한 흐름
4. Product — 사용자 가치로 연결된 네 가지 핵심 기능
5. UI QA — 지도·거리 문제를 실제 화면에서 발견하고 개선
6. Architecture — Flutter, Cloud Run, ADK, Gemini, Firestore, 공공데이터
7. Agent flow — 위치·쿠폰·매장·계산·설명의 순서
8. ADK — 판단과 계산 책임을 분리한 에이전트 설계
9. Public data — 후보 수집 후 쿠폰 브랜드로 필터하고 거리순 Top 5
10. API — 프론트가 사용하는 백엔드 계약
11. Deployment — GitHub에서 Cloud Run/Firebase까지 자동화
12. Troubleshooting — IAM, Secret, 경로, 데이터 품질 이슈 해결
13. Validation — Backend 16 + Flutter 5 = 21 tests, health 200, Top 5
14. Scope — 현재 시연 가능 범위와 다음 확장
15. Close — 프로젝트가 증명한 역량과 링크

Visual system: Codex Grid의 흰 배경·검정 타이포·연회색 패널을 유지하고 쿠폰콕의 따뜻한 노랑(#F7C948)을 한정적 강조색으로 사용한다. 제목은 Noto Sans KR 46px 이상, 본문은 21px 이상. 실제 쿠폰 이미지, 지도 QA 캡처, 자체 제작 아키텍처 도식을 사용한다.
